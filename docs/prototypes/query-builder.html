Pick a filter to start a clause. Tap the pill text to open the keyboard; the sliders key on its bottom row comes back here.

Three ways back to the builder

  • A · Icon in the pill. In typing mode and over results, the magnifier at the left of the pill becomes a sliders glyph. Tap it and the builder comes back with the query kept, ready to Add another clause. One control covers both modes and costs no key space. The magnifier only ever showed in the builder anyway, where it is redundant.
  • B · Key on the bottom row. A sliders key sits between 123 and the globe; the space bar gives up the room. Discoverable in the place people look for mode keys, and it mirrors how 123 switches planes. Works only from typing mode: over results you tap the pill first, then the key.
  • C · Swipe the keys down. A grabber above the syntax row; dragging the keys down slides the QWERTY away and reveals the builder, like closing a drawer. Costs about 12 pt of key height and nothing else, but gestures are invisible until found. Drag the grabber (or the keys) down in the mock-up.

Chosen: B (2026-09-23). The key is drawn like every other function key: same fill, white glyph, 1.25 key units wide like 123 and the globe. From the results grid the route is the pill text, then the key.

What changed from the first round

  • Only the step-by-step layout. Crumbs read Filter, Operator, Value with no numbering, and the Operator crumb is absent for filters with a single operator (Type, Format, Keyword, Card text).
  • No clause tokens, no tinted colour letters, no is: filter.
  • Card text has no value step. Picking it enables Add at once; Add drops o:"" into the pill and opens the keyboard with the caret between the quotes. Other… under Type does the same with t:.
  • The keyboard types for real in the mock-up, so you can finish a clause and press return.
